# 题库目录

放在这里的每一个 `*.json` 都会在**首次启动时自动导入**（文件名即课程名），导入过的课程不会重复导入。

仓库自带的 `示例题库.json` 只有十几道演示题，用来验证流程能跑通，**不含任何真实课程内容**。
你自己的题库请按下面的格式新建文件，例如 `libraries/我的课程.json`。

## 文件格式

和 [AutoCourse-DB](https://github.com/) 的题库格式完全一致：一个扁平的 `字典`。

```json
{
  "[single] 题干 | 选项1 | 选项2 | 选项3": "正确答案的选项正文",
  "[multiple] 题干 | 选项1 | 选项2 | 选项3": "正确答案1#正确答案2",
  "[judgement] 题干（ ） | 对 | 错": "对"
}
```

规则：

- **key** = `[题型] 题干 | 选项1 | 选项2 | ...`，用 ` | ` 分隔（竖线两边各一个空格）。
- **题型** 只能是 `single`（单选）、`multiple`（多选）、`judgement`（判断）。
- **value** = 答案的**选项正文**（不是字母），多个答案用 `#` 连接。
- 判断题的选项固定写 ` 对 | 错`，答案写 `对` 或 `错`。
- 选项顺序不重要：导入时会按正文排序生成稳定 key，所以你自己排的顺序和 OCS 页面的顺序不同也能命中。

## 其它导入方式

- 网页后台「题库」页 → 右上角「导入」→ 直接粘贴 JSON 或选择文件。
- 命令行：`POST /api/admin/import`，body 为 `{"course_name": "课程名", "data": {...}}`。
- 也可以直接放 AutoCourse-DB 原来 `libraries/` 目录里的题库文件，格式兼容。

> 提示：题库属于课程内容，公开分享前请确认你有权分发。本仓库没有附带任何真实课程题库。
